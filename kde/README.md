# KDE Plasma shortcuts

Installed by `kde/setup.sh`.

## Explicit personal shortcuts

| Shortcut | Action |
|---|---|
| `Meta+Alt+Left/Right/Up/Down` | Custom Quick Tile focused window |
| `Ctrl+Alt+Space` | Launch Ghostty |
| `Alt+Space` | KRunner floating search bar |
| `Alt+F2` / `Search` | KRunner alternates |
| `Meta+Shift+S` | Launch Spectacle |

## Notes

- Disables `Meta+Alt+Arrow` directional window focus so custom quick tile can use it.
