# Commit Message Skill

Create concise, useful commit messages.

## Best Practices

1. Write a clear subject line in imperative mood.
2. Add a body only when the change is non-trivial and extra explanation would help.
3. For simple changes, a single clear subject line is enough.
4. Use short bullet points for key behavior, explaining `what` and `why`.
